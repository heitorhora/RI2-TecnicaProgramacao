Prática focada no desenvolvimento de funções construtoras, métodos de acesso (get/set) e manipulação de propriedades em objetos JavaScript.
Parte 1: Criação de objetos contendo métodos de recuperação de valores em caixa alta e caixa baixa, além de um método para exibir as informações formatadas do cliente.  
Parte 2: Implementação de uma função de ordenação robusta que recebe um array de clientes e retorna uma nova lista ordenada alfabeticamente pelo nome.
